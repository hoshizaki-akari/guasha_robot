# FR5 刮痧机器人博士级算法研究｜第十一轮研究报告 R11.0

> **日期**：2026-10-17（北京时间）。**本轮主问题**：从 R10 的“真实 RGB-D 时间戳文本”推进到**真实 16-bit 深度像素与数字涂鸦标注的逐像素审计**，判断人工指定二维位置在深度孔洞和局部几何不连续处的可用性，并界定数字 scribble 与人体实体墨线的构念差异。**交付状态**：本轮在已连接的只读 GitHub 数据环境中读取、解码并统计了三幅公开真实室内深度图及对应的数字涂鸦/语义标签，另解码一幅真实 RGB 图；本地完成 15 项 Python 程序测试及 3 项纯 JS PNG 解码夹具测试。**未**取得 FR5、人体背部、物理画线、独立激光/仿体真值、工具轮廓或六维力数据；**未**在本地容器落地这些完整公开 PNG，联网全量复算仍待外部环境。因此本轮可称“真实像素级审计”，**不可称“真实三维轨迹精度验证”**。
>
> **证据记号**：`F-data`=本轮读取并实际解码完整公开像素文件；`F-text`=核读完整仓库说明/标定文本；`P-paper`=核读论文可访问的部分正文与方法；`A-paper`=摘要级；`S`=官方软件/数据集说明；`I`=继承前轮且本轮未重新全文核读；`M`=本轮数学推导；`X-connector`=连接器内对真实像素运行的分析；`X-local`=本地合成夹具与程序测试；`D`=待执行。**证据等级表示访问深度，不是论文质量评级。**

## 0. 执行摘要：真实像素让“标注点一定有深度”的直觉失效

R10 已用四段公开 RGB-D 采集的 7,468 对已配对时间戳证明：成功配对≠物理同步；会话内中位偏移甚至可恶化 P95 尾部。R10 决定：若仍无 FR5 设备，就转向**公开真实图像像素**，不再堆合成曲面排行榜。本轮遵守这个研究方向，但因本地网络不能直连外部 PNG，改由**只读 GitHub 数据连接器**取得 `tum-vision/rgbd_scribble_benchmark` 仓库的完整二进制 PNG，使用连接器运行环境中的纯 JavaScript PNG 解码器处理原始字节；本地以 Pillow/Numpy 实现等价的重算程序并对合成图做测试。真实像素全量分析发生在连接器环境，**不是本地全量重跑**。

本轮选择 `bedroom_12`、`kitchen_22`、`livingroom_01` 三个公开室内场景，分别读取其 **16-bit 单通道深度 PNG**、**8-bit 索引式 scribble PNG**、**8-bit 索引式语义 GT PNG**，每幅均为 640×480。`kitchen_22` 还读取并解码了 640×480×3 的 8-bit RGB PNG。仓库说明明确：深度图单位是**毫米**；scribble 是人**在图像上的语义标注笔迹**，不是画在人体背部的墨线。我们对各图裁掉两像素边框，在每幅 **302,736 个内部像素**上审计非零深度，并只在 scribble 非零的像素上计算质量代理指标。

| 真实场景 | 图内 scribble 像素数 | 其中深度非零 | 其中深度非零率 | scribble 邻域含深度零值 | 有效中心点与 5×5 中位数差 >20 mm 的比例* |
|---|---:|---:|---:|---:|---:|
| `bedroom_12` | 1,482 | 1,187 | **80.1%** | **27.3%** (405/1482) | **7.6%** (90/1184) |
| `kitchen_22` | 1,003 | 777 | **77.5%** | **25.7%** (258/1003) | **6.6%** (51/770) |

\*分母是 scribble 中“中心深度>0 且 5×5 窗内至少 8 个非零深度”的像素数；**不是全部 scribble 像素**。邻域含零值的定义是四邻居至少一个深度为零，包含中心点本身可能为零的情况。这里的“深度>0”只代表 PNG 里存在正整数，**不代表真实三维正确**。阈值与场景选择均未预注册，结果是探索性审计。

**新决策**：第一部分不应将人工点位/线条分割结果直接送入 `pixel→depth→3D`。先建立**图像标注支持集与深度可观测支持集的交集**，再区分“真实深度可用”“需要再观测”“可在明确模型下插补”“必须拒绝”，并输出连续路径级的空洞段、几何边界和证据版本。**不将填洞后更连续的曲线等同于更准确的曲线。** 这一决定把 R10 的时钟/标定资格扩展为**真实像素支持资格**，仍不宣称构成博士原创算法。

**样本设计**：`bedroom_12`、`kitchen_22`、`livingroom_01` 是方便获取的**便利样本**，不是从 154 张随机抽样，也没有按难度平衡。三幅图共享同一公开项目的标注流程，场景像素彼此空间相关。**统计独立单位是场景/采集会话，不是 scribble 像素**。三场景的百分比仅是三个描述性个案，不做总体置信区间、不称 SOTA、不推断人体皮肤。

**文件语义**：`*_depth.png` 为单通道 16-bit 无符号深度，仓库说明其量纲为 mm；`*_scribbles.png` 与 `*_gt.png` 是 8-bit 索引图，索引 0 为未标注背景，非零是用户在**图像上**画的类别提示；`*_image.png` 是 RGB。语义 GT 的“GT”是**物体类别标注**，不是几何深度真值。scribble 线条也不是实际物体表面上存在的彩色墨迹，因此**不能用它训练或验证真实皮肤墨线的色彩分割、墨水反光或呼吸形变**。

**坐标/标定**：虽能读到 `Calibration/*.yml`，但仓库同时提示部分标定图采用半分辨率，且有 factory/matlab 两套参数。我们尚未完成“哪套内参对应已配准深度”的独立确认，故**不报告由这些 PNG 得出的可信三维坐标误差或法向角误差**。把某个内参随手代入能画出点云，不等于验证其物理尺寸。

## 4. 可审计的真实 PNG 解码与局部像素实验协议

**连接器侧真实运行**：调用 GitHub 只读文件接口，以 `base64` 获取各完整 PNG 的原始字节；用纯 JS 解码 base64、解析 PNG IHDR/IDAT、执行 zlib/DEFLATE 解压、按 PNG scanline filter 0—4 逆滤波；16-bit 深度按**大端两个字节**还原整数，8-bit palette 读取**索引值**而非 RGB 调色板颜色。三个场景各读取深度、scribble、GT；另解码 `kitchen_22` 的 8-bit 三通道 RGB。实际返回 `depth` 形状 480×640、`uint16`，标注形状 480×640、索引 8-bit；RGB 解压后 921,600 字节。文件 blob SHA 与统计记录在 JSON。

**本地运行**：由于本地容器不能联网，真实 PNG 字节没有落地本地；在本地实现 `src/audit_png_pairs.py`（Pillow/Numpy）与 `src/download_source_pngs.py`（联网时下载并校验 SHA），并在人工生成的 16-bit/索引 PNG 上做单元测试。另保存与连接器算法同族的 `src/png_core.js` 和三份**明确标注为合成夹具**的 PNG，验证 16-bit 大端、palette 索引和 zlib 解码。**不得把本地夹具通过写成真实 PNG 已本地复算。**

**像素选择**：为保证 5×5 邻域完整，使用 `2≤x<638`、`2≤y<478`，每图 `636×476=302,736` 个像素。`A(x,y)=1` 当 scribble 的**索引非零**。`V(x,y)=1` 当原始深度整数 `D(x,y)>0`。中心点、四邻域与 5×5 窗均使用未滤波的原始整数；在后续任何插值/平滑前先保存原值和原始有效性。所有阈值为**研究中用于暴露反例的任意代理阈值**：四邻域跳变 `>30mm`、中心与 5×5 中位数差 `>20mm`、5×5 至少 8 个非零样本。

## 5. 数学定义：深度支持集、空洞邻域、局部差异（R11-1…R11-4）

设像素域 `Ω`，人工数字标注集合 `A={p∈Ω:S(p)≠0}`，非零深度集合 `V={p∈Ω:D(p)>0}`。最朴素的**标注位置深度覆盖率**定义为

\[
C_A=\frac{|A\cap V|}{|A|},\quad |A|>0.\tag{R11-1}
\]

它只测“标注位置是否有非零深度”，**不测该深度是否正确**。若某个像素深度是 `84 mm`，也被 `D>0` 计入；因此下一轮还要按设备工作距离与独立深度参考建立**物理范围门**，不能用 `D>0` 当安全许可。

定义四邻域 `N_4(p)`，一个“接近空洞”的代理标记：

\[
H(p)=\mathbf1\bigl[\exists q\in N_4(p):D(q)=0\bigr].\tag{R11-2}
\]

定义有效中心的局部深度跳变代理：

\[
J_{30}(p)=\mathbf1\bigl[D(p)>0\ \land\ \exists q\in N_4(p),D(q)>0:\ |D(q)-D(p)|>30\ \mathrm{mm}\bigr].\tag{R11-3}
\]

5×5 窗内非零深度集合 `W_+(p)`；若中心 `D(p)>0` 且 `|W_+(p)|≥8`，取其**上中位数** `m_5(p)`（偶数个样本时按排序的第 `⌊n/2⌋` 项），定义

\[
M_{20}(p)=\mathbf1\bigl[|D(p)-m_5(p)|>20\ \mathrm{mm}\bigr].\tag{R11-4}
\]

`H/J/M` 是三个**观察到的几何不连续/不一致代理**。它们不等于“测量错误”：真实桌面边缘可能本来有 100 mm 跳变；5×5 中位数可能跨越两个真实表面，把正确前景值改成背景值。R5 的“网格贪心姿态搜索被噪声极值误导”与此逻辑相通。**不能以中位数作为独立真值，再宣布原始深度有 20 mm 误差。**

## 6. 真实像素结果 A：三个场景的支持率和空洞

连接器侧完整解码结果如下。表内的**内部非零率**分母是 302,736 个内部像素；**标注非零率**分母是该场景全部非零 scribble 像素；两者不可混用。

| 场景 | 内部深度非零/302736 | 内部非零率 | scribble 非零/全部 scribble | 标注非零率 | scribble 邻域含零值 |
|---|---:|---:|---:|---:|---:|
| bedroom_12 | 194,969 | **64.40%** | 1,187/1,482 | **80.09%** | 405/1,482 = **27.33%** |
| kitchen_22 | 216,674 | **71.57%** | 777/1,003 | **77.47%** | 258/1,003 = **25.72%** |
| livingroom_01 | 95,498 | **31.54%** | 318/803 | **39.60%** | 564/803 = **70.24%** |

一个具体的反例是 `livingroom_01`：803 个图像标注像素中只有 318 个有非零深度；**若直接把所有数字涂鸦像素当作 3D 点，会在 485 个位置没有原始深度值**。这个“485”只是 `803−318`，不能说是 485 个错误三维点，因为算法可能选择拒绝或重新观测。另一方面，`bedroom_12` 标注非零率高于全图内部非零率，说明不能从全图空洞比例直接推断用户选中的位置空洞比例；必须**按实际轨迹支持集**统计。

零值可能由遮挡、反射、深度重建失败、范围外、注册或后处理引起；仅凭单幅 PNG 无法确定各零值的物理原因。深度非零的最小/最大原始值：`bedroom_12:79—2344 mm`，`kitchen_22:84—6581 mm`，`livingroom_01:79—2807 mm`。这些极值进一步提醒：**正整数不是“可信量程内的正确距离”**，还需要相机型号、量程、置信度和独立参考。

## 7. 真实像素结果 B：四邻域跳变和 5×5 中位数不一致

| 场景 | 标注点四邻域有效深度跳变 >30 mm | 中位数可评估中心数 | 其中与中位数差 >20 mm | 条件比例 |
|---|---:|---:|---:|---:|
| bedroom_12 | 209/1482 = **14.10%** | 1,184 | 90 | **7.60%** |
| kitchen_22 | 145/1003 = **14.46%** | 770 | 51 | **6.62%** |
| livingroom_01 | 120/803 = **14.94%** | 306 | 57 | **18.63%** |

例如，`bedroom_12` 的标注像素 `(x=439,y=22)` 的原始深度为 **1274 mm**，其 5×5 非零值的上中位数为 **1432 mm**，相差 **158 mm**；同场景 `(489,24)` 为 `551 mm` 对 `1738 mm`，相差 **1187 mm**。`kitchen_22` 的 `(260,8)` 为 `3661 mm` 对 `3639 mm`，差 **22 mm**。这些是从真实 16-bit PNG 中读取的原始像素与局部统计，**不是“真实误差 158/1187/22 mm”**；有可能中心处于真实物体边界，恰恰是中位数跨越了表面。

**解释**：本轮没有独立激光真值，不能将 `M20=1` 当“错误标签”，也不能宣布“中位数滤波提高精度”。同理，`J30=1` 可以表示真正的几何边缘，也可以是噪声。最稳妥的动作是**保留原始深度、记录邻域不一致、暂缓把该点加入可执行轨迹，并优先从另一视角或独立参考重新观测**。这不是算法失败，而是正确的证据降级。

## 8. 真实 RGB 与语义标签：完成了什么，没完成什么

本轮从 `kitchen_22_image.png` 读取了完整 881,764 字节 PNG，解析得到 **640×480×3、8-bit RGB**，并在连接器侧完整解压为 921,600 字节像素。三个通道的均值分别为 **94.654、81.489、61.286**（0—255 整数像素尺度），这是验证 RGB 解码和通道顺序的**描述性校验**，并不评价墨线识别能力。RGB 中心像素 `(320,240)` 为 `[0,0,0]`；同位置是否存在有效深度需要联合查询，不能仅从“RGB 黑色”推断深度缺失。

`scribbles.png` 是**palette-indexed** 标注图：像素索引 `0` 为背景，非零索引如 `4、41、53` 表示人工指定的语义类；`gt.png` 的非零类别也是语义区域标签。它们在本轮被解码为整数类别索引，而不是将彩色可视化图再阈值化。这一点很重要：**图像上的彩色 scribble 是标注层，不是摄像头真实拍到的涂料**。如果直接拿这些非零像素去训练“皮肤上的红墨线分割”，会发生**数据构念偷换**：训练目标来自图像编辑层，测试目标却是反光、渗透、皱褶、遮挡的物理标记。

本轮**没有**在真实 RGB 像素上运行墨线颜色分割器，也没有构建 3D 轨迹。原因不是算力不足，而是缺少物理墨线真值和确定的注册/时钟语义。下一轮可在非人体曲面仿体上画物理线，同时记录空白/有线前后 RGB-D，建立真实像素级墨线中心带真值和独立曲面测量，才可以研究分割—深度关联的误差传播。

## 9. 三种算法基线的公平比较与为什么不排名“精度”

| 基线 | 核心操作 | 优势 | 关键风险 | 本轮可报告的指标 |
|---|---|---|---|---|
| **B11-0 直接取深度** | 标注像素 `D(p)>0` 即读取该值 | 无滤波偏差、可追溯 | 孔洞导致缺点；单像素噪声与系统偏差 | 真实非零覆盖率 `C_A`，**不是毫米精度** |
| **B11-1 5×5 非零中位数** | 邻域足够多时用 `median(D>0)` | 可抑制孤立极值；能生成候选填洞值 | 横跨前/背景时制造错误深度；不应静默填补 | 与原始值差异、可评估比例；**无真值不排名** |
| **B11-2 边缘/空洞感知拒绝** | 同时要求中心非零、四邻域无零、无大跳变、与中位数一致 | 把风险显式转成拒绝/重观测 | 可能大量拒绝真实有效边缘，整条路径断裂 | 覆盖—拒绝曲线；**误报/漏报待独立真值** |
| **B11-3 联合 RGB-深度引导** | 以颜色/深度边缘共同定义滤波权重或分割图 | 有望避免跨明显颜色边界的平滑 | 颜色边缘≠几何边缘；实体墨线颜色可能误导 | **未运行，不能写性能** |
| **B11-4 多视角/独立几何参考** | 不同视角、校准仿体/激光建立外部表面 | 能检验单帧系统偏差与遮挡 | 采集与配准成本高、仍需时空标定 | **待实验；唯一可升级精度主张的方向** |

本轮只**实际计算** B11-0 的覆盖、B11-1 的**不一致率**和 B11-2 所需的若干局部风险代理；没有从连接器侧导出 B11-2 的完整接受率，也没有运行 B11-3/B11-4。即使本地代码提供了 B11-2 组合规则，也只能说**规则可实现且通过合成单元测试**，不能写成真实场景“已达到 X% 精度”。本轮保留 B11-0 为强基线，不以复杂性自动胜出。

## 10. 从二维支持集到三维曲面：误差与不可辨识性（R11-5…R11-8）

若注册的 RGB/深度像素共享相机内参 `K=(f_x,f_y,c_x,c_y)`、深度尺度 `s_D` 已核准，则像素 `p=(u,v)`、原始深度整数 `d` 的理想回投影为

\[
z=\frac{d}{s_D},\quad P^C(u,v,d)=\begin{bmatrix}(u-c_x)z/f_x\\(v-c_y)z/f_y\\z\end{bmatrix}.\tag{R11-5}
\]

**对本仓库说明的毫米深度**，候选尺度是 `s_D=1000 raw units/m`；这与标准 TUM SLAM 数据常见的 `5000 raw units/m` **不能混用**。即使尺度正确，如果内参/畸变/注册版本未确认，回投影仍不是可验证三维真值。以 `d=1500 mm` 为纯计算例，`z=1.5m`；若误用 `s_D=5000`，会得到 `0.3m`，造成五倍尺度差。这是**算法接口错误**，不是相机随机噪声。

设二维标注位置误差 `δu,δv`、深度误差 `δz`，一阶扰动为

\[
\delta P^C\approx J_{uvz}\begin{bmatrix}\delta u\\\delta v\\\delta z\end{bmatrix},\quad J_{uvz}=\begin{bmatrix}z/f_x&0&(u-c_x)/f_x\\0&z/f_y&(v-c_y)/f_y\\0&0&1\end{bmatrix}.\tag{R11-6}
\]

深度空洞不是 `δz≈0`，而是**没有观测值**；不能给 `D=0` 填一个极小方差再输出可信点。即使 `D>0`，若处于前景/背景边缘，误差也可能呈**多峰**：该像素可能属于近处物体，也可能是背景，而单高斯协方差无法表达这种类别不确定性。对这些点更适合保留**候选表面假设/拒绝原因**，而不是强行平均。

若 `p_i` 形成一条路点序列，令每点是否有独立有效深度为 `V_i`，则“整条轨迹所有路点均有原始深度”的最朴素资格是

\[
E_{\rm all}=\prod_{i=1}^{N}V_i.\tag{R11-7}
\]

这是**严格布尔条件**，不是概率模型；如果 100 个点中 1 个没有深度，则 `E_all=0`。实际可以设计“可重观测的连续缺口长度”与“局部替代路径”，但不得在缺口未知时假定“样条曲线跨过去就是正确曲面”。更不能把 1,000 个相邻像素当 1,000 个独立成功试验：同一遮挡边缘会产生连续相关空洞。

跨时空与工具误差仍需联合：

\[
\Sigma_{P^B}\simeq R_{BC}J_{uvz}\Sigma_{uvz}J_{uvz}^{\!T}R_{BC}^{\!T}+J_T\Sigma_TJ_T^{\!T}+\Sigma_{\rm common}+\Sigma_{\rm cross},\tag{R11-8}
\]

这里的 `Σ_common` 含整张图共享的深度尺度、注册和手眼偏差，`Σ_cross` 含相关项。R6/R9 的“越多观测越自信却更错”仍适用。**R11 新增的不是另一种滤波器，而是将“没有深度观测”和“观测存在但可信度不足”分成两种不同的数学状态。**

## 11. 人工点选与实体画线：两个输入通道不能混淆

**入口 A `MANUAL_POINTS`**：操作者在**冻结的真实 RGB 帧**上点选一个或多个像素，记录源 RGB ID、UI 点击时刻、点击坐标及交互版本。UI 点击时刻只是人点击按钮的时间，**不是曝光时刻**。将点击映射到深度时，必须先验证 RGB 与深度的时间/注册语义，再检查原始深度是否存在、是否处于边缘/孔洞、是否有独立校准证据。对 `D=0` 的点输出 `REOBSERVE` 而不是 `(0,0,0)`；对边缘多假设点输出 `AMBIGUOUS_EDGE` 而不是伪造高精度法向。

**入口 B `SKIN_MARKER`**：操作者用实际可见材料在非人体仿体（最终才考虑人体）表面画线，RGB 算法应分割**物理标记带**、估计中心线及其宽度/方向不确定性，然后对带内每个位置查询深度支持。数字 scribble 数据集能让我们先研究“给定 2D 标注像素时深度可能缺失”，但不能验证墨水颜色、笔迹渗透、皮肤纹理、反光、呼吸位移和标记移动。下一轮必须同时采集“未画线背景”“画线后 RGB-D”“独立三维仿体参考”，否则这条入口仍为**实验设计**而非已验证功能。

**共享输出**：`SurfacePathCandidate` 携带 `input_mode`、原始像素/标注支持集、时间戳与时钟域、相机模型/尺度/注册版本、局部曲面候选、空洞段、边缘歧义、重观测请求、协方差或多假设表达、工具覆盖区域与**整条路径**资格。**不得**用图像 scribble 的像素数替代真实实体墨线的路径数，更不得用分类 GT 当几何 GT。

```json
  "path_id": "uuid", "input_mode": "MANUAL_POINTS | SKIN_MARKER",

  "tool_geometry_version": "id | null", "wrench_calibration_version": "id | null",
  "reason_codes": ["string"]

```

`PROXY_AUDITED` **绝不自动升级**为 `INDEPENDENTLY_VERIFIED`；`digital_scribble_proxy` **不得标记为** `physical_ink`。如果只有 RGB 画线、深度注册版本不明或有连续空洞，系统只能返回“需要补证据”，不能输出实体可执行轨迹。原始深度、插补深度、独立参考深度必须分字段保存；所有插补结果携带 `method_id` 与依赖的邻域/帧版本，避免被下游误当原始传感器观测。

在 ROS 2 映射中，可由消息承载上述字段，但 `header.stamp` 仍须说明物理时间语义。第二部分的刮板 CAD 查询应消费**路径覆盖区域与缺口信息**，而不是只消费一串平滑 TCP 中心点；第三部分的工作程恒力/返程轻力状态机必须在非人体台架用独立接触测量验证。当前接口**不定义力数值、速度或人体剂量**。

## 14. 统计、敏感性、失效模式与研究限制

**统计单位**：3 个便利场景而非 3,288 个独立 scribble 试验；同一笔划的相邻像素共享遮挡和深度模型偏差。任何把像素当独立样本计算极窄置信区间的结果都无效。报告只给出**描述性比例**，不报告跨场景总体显著性。**阈值敏感性**：`20mm` 中位差和 `30mm` 邻域跳变是探索性选择；不同距离、传感器、纹理和曲率下应按独立参考校准，不能因为在这三图上“看起来合理”就冻结。**分母敏感性**：中位数差异比例只对“中心非零且 5×5≥8 个非零”子集成立；空洞点被排除会产生选择偏差。

**物理失败情形**：深度零值可能聚集成连续缺口；强反光/黑色材质可能造成缺测；真实几何台阶会使中位数把前景点拉到背景；RGB 颜色边缘不一定是深度边缘；画在皮肤上的墨线颜色可能改变 RGB 边缘却不改变深度；呼吸形变使不同时间的颜色与深度不能对齐；不同相机标定/安装版本会造成整条曲线共模漂移；有限刮板边缘需要的曲面范围可能比标注中心线宽得多；腕力恒定不代表局部压力恒定。

**可复现性限制**：真实 PNG 的完整字节和统计在只读连接器侧处理，**未在本地容器下载/存档**。本地 Python 源码提供 Git blob 哈希验证和重算；15/15 本地 Python 测试只用合成数组，3/3 Node PNG 测试只用合成 PNG，**不证明本地真实图像已重算**。结果 JSON 含每个文件哈希、指标分母和计算定义。若在可联网机器重算出现差异，必须优先检查 PNG palette 索引、16-bit 大端、上中位数、2 像素裁边和源版本，而不能先修改结果表去“对齐”。

**外推限制**：三幅都是室内物体，不是皮肤；数字 scribble 是交互式分割提示，不是物理墨线；语义 GT 不是 3D 真值；没有时间戳、法兰、腕力、工具轮廓、人体安全阈值。因此，**本轮不能宣称三维轨迹毫米级精度、刮板贴合、恒力控制或人体适用性**。iBims-1 和 Bonn 是候选外部参考，尚未执行。

## 17. 复现包、双文档内容验收与最终结论

**文件清单**：`src/audit_png_pairs.py`（Pillow/Numpy 真实 PNG 重算，2 像素裁边、深度/标注统计、Git blob SHA）；`src/download_source_pngs.py`（用户可联网环境自愿下载源 PNG，校验 SHA）；`src/png_core.js`（连接器侧所用纯 JS PNG/DEFLATE 解析核心的本地同族版本）；`tests/test_audit.py`（15 项合成数组/PNG 测试）；`tests/test_png_core.js`（3 项合成 PNG 解码测试）；`data/test*.png`（**合成测试夹具，非真实采集**）；`results/connector_pixel_audit.json`（连接器真实像素结果、原始计数、版本）；`results/unit_test_log.txt`、`README_REPRODUCE.md`、`SHA256SUMS.txt`。源数据受原仓库许可约束，本包**不重分发**原始真实图像。

**测试结果**：本地 Python `15/15` 通过，Node 纯 JS `3/3` 通过；测试验证算法分母、阈值边界、深度空洞、局部中位数、SHA 拒绝及 PNG 解码夹具。**尚未**在本地用真实 PNG 全量运行 `audit_png_pairs.py`；结果 JSON 的真实数字来自连接器侧处理。报告中的 3 幅图只是**三次便利选取的真实室内采集**，不能据像素数推断显著性。

**双文档验收规则**：学术报告 `0—17` 共 18 章；教学讲义须对应 18 章，逐项解释 **R11-1…R11-8** 八个公式、**L11-01…13** 十三项来源、**H11-1…8** 八项假设、**ADR-R11-01…11** 十一项决策、**WP12-A…F** 六个工作包及全部数值表，尤其第 9—17 章不得变成摘要。QA 脚本检验章节标题、标识覆盖和每章最低讲解篇幅；它不是零基础学生实际学习成效测验。

**结论**：R11 实际迈出了 R10 要求的**真实像素级证据**一步：在三个公开室内 RGB-D 场景中，二维数字 scribble 的深度非零覆盖率分别只有 80.1%、77.5%、39.6%，并且大量标注点邻近空洞或局部深度跳变。它推翻了“只要图像上有笔迹，深度图就一定能直接给出三维曲线”的简单假设；但没有独立几何真值，**不能断言哪种填洞/滤波更准确**。下一轮优先完成本地真实 PNG 双实现复核和独立几何参考，随后才进入**实体墨线→三维曲面轨迹→实测刮板接触→双向力控**的非人体实验链。
