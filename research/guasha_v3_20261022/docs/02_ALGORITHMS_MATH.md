# 完整数学算法细化与实现说明｜供AI编码推导和审查

> 本文件与`01_MASTER_SPEC.md`配套；绝非真实设备参数/医学处方。所有变量、方向、离散步长、模型输入的量纲必须在代码中逐条写清。每个公式至少有正常值/退化值/已知真值测试。

## A1. RGB-D几何、畸变、对齐和多坐标系

相机内参 `K=[[fx,0,cx],[0,fy,cy],[0,0,1]]`。对于已去畸变并对齐的深度像素 `(u,v)`、原始深度单位 `d_raw`：`z=d_raw*scale_m_per_unit`，`p_C = z * inv(K) @ [u,v,1]`，即 `X=(u-cx)z/fx; Y=(v-cy)z/fy; Z=z`。这里z是**相机光学坐标Z分量**，不是欧氏射线长度；不能混淆。深度=0/NaN/超范围应标记缺失。若RGB与深度没有像素注册，必须先用`T_Crgb_Cdepth`和深度相机内参进行重投影及遮挡z-buffer，不能把相同`(u,v)`当对应点。

SE(3)：定义 `T_A_B` 把B点转换到A坐标，`p_A=R_A_B p_B+t_A_B`；`T_A_C=T_A_B T_B_C`；`T_B_A=T_A_B^{-1}`；利用固定种子随机变换测试链的闭环一致性、逆变换恢复、右手坐标与角度度量。合成手眼标定AX=XB，需保证A、B的定义与OpenCV的`calibrateHandEye`参数一致（官方API返回gripper2cam或cam2gripper要逐式核对）；使用非共面、多旋转轴的合成姿态产生观测、加入噪声，离线留出姿态评估；不能把单次残差小当作独立精度证明。

输出误差可选一阶线性传播：`Σ_p≈J_pixel Σ_pixel J_pixel^T + J_depth σ_z² J_depth^T + J_ext Σ_ext J_ext^T`，严禁忽略depth-scale误差与外参误差后宣称绝对毫米精度。以观测数据提供质量等级，不要把自报confidence当成概率校准已验证。

## A2. 屏幕线到RGB像素的正确转换

给出屏幕画布本地坐标`c=(x,y)`、可见原图裁剪 `(x0,y0,w_crop,h_crop)`、显示尺寸`w_d×h_d`。若不保留原始纵横比，必须知道独立缩放；若保留比例且有黑边letterbox，则记录`scale`和`offset_x/y`；通用仿射`[u,v,1]^T = H_canvas_to_rgb*[x,y,1]^T`，并检查落在RGB有效区域。

M1输入离散有序点击(`order`，绝不排序按x/y坐标)；M2输入连续采样stroke，至少包含`stroke_id`, `t_ns`, `x_canvas`, `y_canvas`, `button_down`, `transform_id`，按采集序而非图像中的几何位置排序。纯离线没有真实UI时，输入JSON中的画布坐标代表模拟用户笔迹，但必须有同等变换算法与测试。

对原始stroke先保序去抖：重复位置去重和短噪声步长限制；可用Ramer–Douglas–Peucker简化，保证最大图像平面距离epsilon_px；插值使相邻像素采样步长 ≤ `delta_px_max`。若笔迹交叉保留绘制时序，不作骨架追踪的端点猜测；多stroke除非明确批准拼接，不自动连线。对每个采样点读取注册深度，必要时只允许受控的局部同一曲面中位数补点，补点数量/连续长度超过配置阈值则拒绝；把这些阈值标为`SYNTHETIC_DEFAULT`。

## A3. 深度邻域PCA、法向方向与局部二次拟合

邻域有效点 `q_j∈R³`，权重 `w_j≥0`，`μ=Σw_j q_j/Σw_j`，`C=Σw_j(q_j-μ)(q_j-μ)^T/Σw_j`。特征值排序`λ0≤λ1≤λ2`，`n=eigvec(λ0)`。当`λ1`也接近0代表邻域几乎退化为一条线/一点，应拒绝。平面区域若`λ0≈0`且`λ1,λ2`较大反而很好；不要把平面误判为退化。局部平面残差`r_j=n·(q_j-μ)`，可用MAD评价离群；保持`n`朝向相机或规定外法向，并用相邻点传播符号，必须记录选择的规则。

增强：局部切平面基`a,b`建立`h(a,b)≈c0+c1 a+c2 b+(1/2)c3 a²+c4 ab+(1/2)c5 b²`，加权鲁棒最小二乘（Huber IRLS）拟合；求一二阶导得到法向与近似曲率。如果二次拟合残差/条件数高于PCA，应拒绝增强而回退PCA。比较PCA和二次曲面拟合在已知球/柱/平面和深度缺洞上的角误差、曲面偏差与耗时，不能直接假设增强一定更好。

## A4. 曲面路径、弧长采样与回投影

给离散3D点`p0...pn`，弧长`s_i=Σ_{j<i}||p_{j+1}-p_j||`。以间隔`ds`通过单调插值获得候选样点，随后用局部有效点云上的最近表面/射线重投影至曲面；必须限制最大移动距离和跳跃至不同物体的概率（可以用深度连续性法向约束）。禁止为使轨迹连续而跨越连续无深度区强行插值。计算切向`t_i=normalize((p_{i+1}-p_{i-1})-n_i[n_i·(p_{i+1}-p_{i-1})])`，端点用单边差分。若切向与法向数值平行或长度极小则标记`TANGENT_INVALID`。

当点间路径需要沿曲面避障，可构建邻接图V,E，边权`c_ij=alpha*||p_i-p_j||+beta*φ_curvature+gamma*φ_confidence+delta*φ_no_go`，各项非负且可消融，对不可执行边设`+∞`。M3需实现Dijkstra，可选A*的启发函数`h(v)≤实际余下可行路径代价`，否则不能保证最优。S2覆盖模板要处理多线间距、顺序、曲面投影、方向和区域越界。输出路径失败时要区别`NO_GRAPH_ROUTE`与`SURFACE_GAP`。

## A5. 有限宽刮板的几何姿态和接触轮廓

曲面法向`n`、路径切向`t`，令`t'=normalize(t-(t·n)n)`，横向轴`e=normalize(n×t')`。若拟定义刮板工作边缘横跨e，则边缘候选点`b(s)=p_center+s e`, `s∈[-w/2,w/2]`；真实刮板的刃口可能不是直线，必须支持局部多段几何与装配偏转。法向攻角β需绕明确工具轴旋转（SO(3) `R=R_surface R_mount R_attack(β)`），未知β只用于标明`SYNTHETIC_TOOL`的仿真。保证三轴右手正交、四元数在相邻样点做符号连续化。

扫掠区采样：对路径每个线段做小于设定弧长的离散插值，对每个中间样点在刮板边缘取5–21个横向支点；检查到曲面的距离、近邻法向跳变、深度质量与禁区。离散检查不能证明连续全域安全，需提供速度/曲率/尺寸 Lipschitz 上界或保守包围体，若无可信界，输出`CONTINUOUS_SWEEP_NOT_CERTIFIED`；测试用两采样点之间藏尖峰障碍的反例确保拒绝。距离误差要包含曲面点云观测的不确定性，不能只算已知理想几何。

## A6. 6D wrench和接触力的坐标/原点

假设传感器S相对新坐标C的旋转R_C_S，两个原点坐标在C下分别`p_S`, `p_C`。传感器测得`F_S`,`τ_S`（τ_S关于S原点）。则`F_C=R_C_S F_S`，`τ_C=R_C_S τ_S + (p_S-p_C)×F_C`。测试一组简单值如`F=(0,0,10)N; p_S-p_C=(0.1,0,0)m`应产生`τ=(0,-1,0)N·m`（实际方向依照明确坐标约定）。错把力矩当作只旋转不平移会造成伪偏载。

静态补偿步骤：在`NO_CONTACT`合成观测下先估计偏置`b`，再基于工具质量m与相对质心`r_com`及姿态计算工具重力wrench `g(q)`，`w_contact = w_sensor - b - w_gravity(q)`；模型未知/运动加速度大时额外动力学项会引入不可忽略误差，应标`COMPENSATION_LIMITED`并降低/拒绝估计。定义曲面n方向：若n向外，压向物体的接触反作用可能与-n或+n一致，须在代码中强制记录`force_sign_convention`并单测。法向量测`F_n=n^T F_contact`的物理解释依所定方向而定。

同步：没有F/T时间戳或同一控制步时间差>设定最大延迟时`STALE_WRENCH`。滤波须记录采样频率和窗口，相位滞后不能被当作真实快速响应。

## A7. 等效接触偏移的可辨识性与可靠拒绝

若仅在已知边缘方向e、已知参考r0、合力F且**忽略未知自由力矩μ**的简化模型成立时：`τ≈(r0+s e)×F`。令`a=e×F`，`b=τ-r0×F`，最小二乘 `s_hat=(a·b)/(a·a)`。当`||a||²≈0`（即e近似平行F或F很小），s无法估计；有多个未知接触位置/边缘旋转自由度或摩擦偶矩时同样不能唯一确定。且`s_hat`是**等效合力作用线位置在边缘方向的投影**，并非每个横向位置的压力值。

令残差`ρ=||b-s_hat a||`，只有力质量、几何校准、残差、`|s_hat|≤w/2+margin`和估计条件数符合仿真设定的Gate才给出`IDENTIFIABLE_UNDER_ASSUMPTIONS`；否则`UNOBSERVABLE`。至少构造2种不同分布式接触力、合wrench相同的反例，检测算法不会据相同wrench断言不同的局部分布。作为控制输入时，偏载纠偏仅在可信区间内小角度/小速度启用；不可信时回退基础导纳，不允许为保持效果持续放大控制量。

如果允许未知边缘角度θ与未知偏移s同时存在，单一标量力矩一般不足以同时估计两个未知量。要添加新的可辨识传感线索、独立局部力真值，或者把一个变量固定并说明假设。后期AUTO总结提示了这一点，但其各轮原始文档缺失，需保留证据级别。

## A8. 简化接触物理模型和真值隔离

对每一刮板边缘点/段j，定义曲面无载高度`h_j`和沿法向的虚拟工具压入量`δ_j=max(0,h_j-z_tool,j)`，法向速度`δdot_j`。Kelvin–Voigt `f_n,j=max(0,k_j δ_j+c_j δdot_j)`，单位：`k_j N/m`, `c_j N·s/m`；强非线性时可替换`f_n,j=max(0,k_j δ_j^a(1+α δdot_j))`并处理非负约束。侧向摩擦`f_t,j=-μ_j f_n,j * smooth_sign(v_t,j)`，不允许零速度数值除0。合力`F=Σ (f_n,j n_j+f_t,j t_j)`，合力矩`τ_S=Σ((p_j-p_S)×f_j)+τ_free,j`。这种模型只测试数值实现和策略条件，不能把刚度系数或安全阈值投射到真人皮肤。

**真值隔离**：每一步仿真内部真实`δ_j`, `f_n,j`, `p_j`给评估器；控制器只读`F_meas`, `τ_meas`, 视觉曲面估计及历史状态。可插入倾斜接触、一端软化、两侧不同刚度、摩擦变动、滞后和传感器掉包。若控制器能访问真值，视为数据泄漏，测试应失败。

## A9. 控制器（仅合成执行器）与稳定性测试

定义路径沿切向弧长s(t)，法向位置调整量x(t)；合成执行器支持最大法向速度、加速度和总位移，超限时截断且积分器抗饱和。

- `C0`开环几何参考：x(t)=x0(t)，忽略F反馈，构成无反馈下限；
- `C1`法向力PI位置增量：`e=F_target-F_meas`，`I_{k+1}=clamp(I_k+e_k dt,Imin,Imax)`（饱和/符号应调到接触模型下的负反馈），`dx=clamp(Kp e+Ki I,dxmin,dxmax)`；对接触向下为正与符号定义做实验，不要照搬增益到实机；
- `C2`离散导纳：`M a_k + B v_k + K x_k = e_k`，`a_k=(e_k-B v_k-K x_k)/M`，`v_{k+1}=clamp(v_k+a_k dt,±vmax)`，`x_{k+1}=clamp(x_k+v_{k+1}dt,[xmin,xmax])`。接触误差e符号随坐标系选定一致。应记录`dt`/延迟/饱和状态，测试多步长下是否发散，不以“连续时间稳定”推断离散时延稳定。
- `C3`在C2基础上加受限可信融合：视觉法向作为几何先验、F/T作为力状态，残差+可辨识性共同决定是否执行有限幅姿态修正；`correction=gate*clip(K_theta*s_hat,±theta_step_max)`，`gate=0`时回退C2。不得凭单一负载力矩自动反推二维压力场。

共同试验在**相同生成场景+相同噪声种子+相同控制率和离散求解器**下运行。评价：`RMSE(F_target-F_meas)`、法向峰值/超调、建立接触时间、法向运动误差、单边接触/掉接触率、异常拒绝正确率、卸载后力接近零的时间、最坏超限程度。采用多种刚度、摩擦、曲率、延迟情形统计平均±标准差与失败频次，说明模拟器偏置，不凭合成仿真结论宣称论文算法有新意。

## A10. 状态机与安全退出

FSM的状态转换不是定时播动画。`PRECHECK`必须看到有效深度/路径/法向/工具配置/仿真批准；`APPROACH`只推进到模型内安全距离；`CONTACT_RAMP`低速建立接触，并有超时/峰值异常；`WORK`仅当接触标志和F/T时效有效；`UNLOAD`把目标力缓慢归零并检查合成力下降；`OFFSURFACE_RETURN`确认无接触后才反向回起点；`DONE`记录；异常转`HOLD/ABORT`并冻结或撤退。`LIGHT_RETURN`不是默认模式。

所有阶段的`t_ns`, `state`, `trigger`, `input_hash`, `F_meas`, `F_true`(仅评价通道), `pose_sim`, `reason`可复现实验记录。至少每种状态有进入/退出正常测试，各异常需能在随机中途故障注入后到达可确认拒绝状态。**这些都只是数值仿真中的状态，不等于任何真实机器人安全PLC/控制器。**

## A11. 独立对照和误差传播

每个模块至少一个可手算或独立公式真值，不使用算法自身输出当真值：平面/圆柱/球法向解析解，投影像素的解析解，简单直线图Dijkstra手工最短路，已知wrench原点平移，二点接触与已知接触合力矩，指定刚度接触解析极限。跨模块测试覆盖观测噪声、标定误差、离线相机变换、深度缺洞、宽工具扫掠和时间戳超限。

推荐统计预注册至少5个独立随机种子（资源允许可更多），对照C0/C1/C2/C3；结果不达标允许如实报告C3无收益。任何研究假设失败应形成`FAILED_HYPOTHESIS`而非悄悄换测试。
