# FAIRINO FR5 刮痧机器人博士级算法研究｜第十五轮研究报告 R15.0

> **研究日期**：2026-10-18。**阶段**：源码/官方技术资料核验 + 本地可复现的解析场景离线反例；**不是** FR5、真实 RGB-D、实体墨线、人体或力控实验。目标系统为 FAIRINO FR5、末端 Eye-in-Hand RGB-D、六维腕力觉、有限宽度刮痧板。第一阶段只允许人工点选与人工确认的实体画线有序路径；自动点位识别后置。**本轮新结论**：即便相机内外参完全正确，深度到 RGB 的前向注册仍会因视角遮挡、离散落点与重采样出现“少数已接受点有巨大错误”；图像级 P95 可以掩盖这种接触任务风险。对偏移前景的反例，简单深度边缘拒绝未能清除多数错误，因而不能把“加一个边缘门”作为已收敛的通用答案。

## 0. 执行摘要、主要变化与验收边界

上一轮 R14 发现 TUM RGB-D Scribble 注册示例按变量名传入 Color→IR，而 OpenCV 官方契约是源深度 K→目标 RGB K。R14 只证明两种参数角色投影不同，未证明公开成品 PNG 错误。本轮不重复 9 点比较，而检验更强命题：**假定我们已经修正了相机角色、知道正确外参，三维曲面轨迹是否就可直接使用？**答案仍是否定的。官方 RealSense 遮挡白皮书（网页标注最后更新 2026-02-12）已完整讨论 z-buffer、空洞与遮挡；它是已知工程基础而非本项目原创。

本轮用仓库标定文件的数值作**合成参数**，构造解析可求交的背景倾斜平面和两种前景矩形薄片；分别从 IR 与 RGB 相机投射光线，**独立**生成源深度与目标真值。比较七种注册/拒绝方法、三种场景、三种缺测条件，共 63 个方法—场景—缺测组合；每组合检查 307,200 个 RGB 像素，另检查 189 条预设图像路径记录。36/36 单元测试通过。这些组合不是独立真实采集会话，不能统计推断 FR5 性能。

**新判断**：保留“正确角色 + 前向 z-buffer”作为注册基线；修订“只要配准契约正确就足够”的隐含假设；**推翻**“局部深度边缘拒绝必然消除遮挡错误”；增加 `TargetVisibilityEvidence`、目标 RGB 边缘/深度一致性及**完整有序路径**的资格与弃权机制。对未知目标视角遮挡，优先重观测/人工确认，不通过插值强行填满。下一轮若无实物与原始 PNG，应把证据缺口标为阻塞，不能继续累积合成排行榜当作实体进展。

## 3. 科学问题、反事实设计与可证伪范围

`Q15-A`：在正确 K/Rt、无噪声解析场景中，前向注册是否必然给每个 RGB 像素可靠深度？可证伪：出现空洞/遮挡错配即否。`Q15-B`：图像级 P95 很小是否能排除边缘巨大错误？可证伪：同时报告最大误差与超预算已接受点。`Q15-C`：简单 2px 深度跳变拒绝是否在所有场景清除错配？可证伪：偏移前景残余错配。`Q15-D`：UV 单调性遮挡剔除是否能解决目标视角独有的可见性？可证伪：目标相机看见而深度相机不可见的区域。`Q15-E`：这些合成发现能否转成 FR5 毫米精度或人体安全？**不能**；缺独立实体证据。

区分三类“真值”：本轮**解析真值**来自同一人为构造的几何场景，但目标 RGB 与源深度分别求交，避免用待测注册输出当真值；它不是独立实物计量真值。真实 TUM PNG 的语义 `gt` 不是深度真值；iBims 激光真值是另一批场景，不能直接作 TUM PNG 的配对真值。只有同场景独立测量或可追溯靶标才能给真实误差资格。

## 4. 两相机、视角遮挡与数学模型 R15-1—R15-3

约定 `D` 为深度相机坐标，`C` 为彩色相机坐标，`B` 为 FR5 基座，`E` 为法兰，`G` 为刮板。`K_D/K_C` 为像素内参，`T_CD=(R_CD,t_CD)` 把 D 坐标转到 C。深度 `z` 是光轴 z 分量而不是空间斜距；本轮无畸变，物理执行须补充镜头模型。

\[
\mathbf p_D=z_D K_D^{-1}\tilde{\mathbf u}_D,\quad
\mathbf p_C=R_{CD}\mathbf p_D+\mathbf t_{CD},\quad
\mathbf u_C=\pi(K_C\mathbf p_C),\qquad \pi([x,y,z]^\top)=[x/z,y/z]^\top.\tag{R15-1}
\]

RGB 真值不能直接从源深度数组取相同下标。对 RGB 射线 `r_C=K_C^{-1}[u_C,v_C,1]^T`，在 D 坐标中令 `o_D=-R^Tt`、`d_D=R^Tr_C`（这里 R 经 SVD 投影到 SO(3)），与背景平面 `z=1.22+0.06x-0.035y`、前景矩形薄片 `z=0.76` 取最近正交点；目标轴向深度 `z_C^*=\tau_C`。源深度独立用 D 相机射线求交：

\[
\tau_{\mathrm{bg}}=\frac{1.22+0.06o_x-0.035o_y-o_z}{d_z-0.06d_x+0.035d_y},\quad
\tau_{\mathrm{fg}}=\frac{0.76-o_z}{d_z},\quad
\tau^*=\min_{\mathrm{valid\ intersections}}\{\tau_{\mathrm{bg}},\tau_{\mathrm{fg}}\}.\tag{R15-2}
\]

源深度映射到目标 RGB 整数像素 `j=round(u_C), k=round(v_C)`，若多个源点落到同一目标像素，保留**目标相机轴向深度最小**的值；没有源投影时标为无效：

\[
\hat z_C(j,k)=\min_{i:\,\mathrm{round}(\pi(K_C(Rp_{D,i}+t)))=(j,k)}(Rp_{D,i}+t)_z,\quad
\min\varnothing=\mathrm{NaN}.\tag{R15-3}
\]

z-buffer 只在“已有投影点”之间选择前面一个，不能创造**只在 RGB 视角可见**的表面。两个相机位置不同使视线不同；某些 RGB 射线穿过前景，但源深度相机同一方向被别的物体遮挡，或者反之。这是信息缺失，不是增加滤波器参数就必然可解的问题。

## 5. 解析场景与运行协议：参数、独立真值、对照

本地脚本 `visibility_audit.py` 使用 L15-04 的 `K_D/K_C`、`t_CD=(0.0262739,-0.0002152,0.05389)m` 和 YAML 的近似 R；原 YAML 旋转因数值截断非严格正交，本轮通过 SVD 取最近正交旋转 `R=UV^T`，以保持解析光线的刚体一致性。该处理与 R14 直接使用截断矩阵的九点审计不同；**两轮数值不可混当同一运行条件**。场景：`plane`（仅倾斜背景）；`patch`（中央矩形前景）；`offset_patch`（偏移矩形前景）。前景薄片是假想遮挡物，**不是皮肤模型**。每场景有 `clean`、固定种子 1515 的随机5%源深度空洞、固定 20×20 源深度缺块三种条件。图像 640×480，无相机噪声、镜头畸变、曝光差或运动。

| 方法 ID | 具体算法 | 所依赖的假设与不可忽略的失败模式 |
|---|---|---|
| **B15-0** `index_copy` | 原 IR 深度按 RGB 同像素取值 | 仅同坐标/同轴才成立；这里连 z 轴都不同 |
| **B15-1** `zmin_correct` | 正确 K/Rt 前向投影、最近深度 z-buffer | 无法补目标独有可见区域；离散空洞 |
| **B15-2** `last_write` | 正确投影但同一目标像素由最后遍历点覆盖 | 遍历顺序相关，可能以背景覆盖前景 |
| **B15-3** `swap_intrinsics` | 错误交换源/目标 K 角色后前向 z-buffer | 模拟 R14 源码契约疑点的条件性错误，不代表成品数据 |
| **B15-4** `horizontal_fill2` | 正确 z-buffer 后按左右 1、2 像素最近值补空 | 能提升覆盖，可能跨越遮挡边界并制造错误接受 |
| **B15-5** `edge_guard2` | 正确 z-buffer 后检测相邻深度差 >0.10m 并剔除2px带 | 只有**已观测**深度跳变才能报警；可能漏目标独有遮挡 |
| **B15-6** `uv_monotonic20` | 源图每行检查前20列 UV 投影逆序并拒绝 | 受 RealSense 文档启发的**简化独立实现**，非 SDK 复刻；只检测特定源视角逆序 |

`>0.10m` 跳变、2px 半径、10mm 错误接受阈值、前景厚度和所有场景尺寸仅为**合成反例预设**，不是医疗、人体、FR5 或刮痧控制安全阈值。代码记录每像素被接受、绝对轴向误差、条件性错误接受率、总像素错误接受率、覆盖率、最大误差、P95。像素彼此高度相关，不能把 307,200 像素当 307,200 独立样本做置信区间。

| 纯背景平面 / 无缺测 | 0 | 0 | 0 | 0 |

中央前景上“边缘拒绝全部有效”不能推广到偏移前景：B15-5 在偏移前景仅剔除 1/66 个错误点。**修订**原本容易出现的路线误判：不能简单宣布“2px 边缘门解决遮挡”。B15-6 的简化 UV 单调性在本构造下也未消除目标视角错配；这**不等于否定 RealSense SDK 正式算法**，因为本实现简化且要解决的可见性方向不同。

进一步使用目标**解析真值**进行非部署的诊断：中央前景 24 个错误点全部属于“目标射线与源相机可见性不一致”集合；偏移前景 66 个错误点中 65 个属于该集合。诊断需要知道真实目标几何，真实机器人并无这种 oracle。纯背景场景也有约8.66%目标像素无法在源像素栅格获得近邻几何对应（包含视野边界与取整），这不能全部称为真实遮挡。故下一轮必须将 `out_of_FOV`、`raster_hole`、`source_occlusion`、`target_occlusion` 分开计量。

## 8. 完整有序路径与接触资格 R15-4—R15-5

预置三条 RGB 图像路径：水平 `y=240,x=80..560`（481点）、垂直 `x=320,y=60..420`（361点）、上边界 `y=193,x=80..560`（481点）。每条路径是**合成图像路点**，不是人体画线或机器人姿态。中央前景/无缺测的水平路径：B15-1 覆盖 **98.34%**，0 个已接受点超过10mm，但**不是完整可执行路径**；B15-2 同覆盖下有5个错误点，B15-3有18个，B15-4覆盖 **99.17%** 但出现1个错误点，B15-5覆盖 **97.09%**、0错误。全路径缺点必须返回 `REOBSERVE` 或 `HOLD`，不能因高覆盖率而自动跨过缺口。

\[
A_i=\mathbf1[\hat z_i\text{有效}\land \text{角色/时间/标定合格}\land \text{目标可见性合格}\land \text{独立几何误差合格}],\quad
A_{\mathrm{path}}=\bigwedge_{i=1}^{N}A_i.\tag{R15-4}
\]

\[
\mathrm{FAR}_{\mathrm{accepted}}=\frac{\sum_i\mathbf1[A_i^{\mathrm{image}}=1\land |\hat z_i-z_i^*|>\epsilon]}{\sum_i\mathbf1[A_i^{\mathrm{image}}=1]},\quad
\mathrm{coverage}=\frac{\sum_i A_i^{\mathrm{image}}}{N},\quad \epsilon=10\mathrm{mm}\ (\text{仅合成演示}).\tag{R15-5}
\]

`A_i^{image}` 是算法仅据图像是否输出的接受状态，**不是**真实部署中包含独立几何真值的 `A_i`。不能在现场直接计算 R15-5 分子，因为没有真值；它是离线评测量。全路径布尔门过严时，可把笔划分成可证实的子段并要求操作者重新确认连接，但不自动用“连续插值”跳过缺测。

## 9. 方法适用假设与信息极限 R15-6

一个重要的信息论层面事实：给定**单帧源深度**，目标 RGB 某条射线看见的表面可能完全不在源深度可见集合中。设 `V_D` 是源深度可见表面点集，`V_C` 是 RGB 可见表面点集。单帧前向投影最多给出 `V_D` 在 C 视角的投影，无法确定 `V_C\setminus V_D` 的真实几何：

\[
V_C\setminus V_D\ne\varnothing\quad\Longrightarrow\quad
\text{仅由单帧 }D\text{ 的确定性重采样不能唯一恢复该区域深度}.\tag{R15-6}
\]

这不是说神经补洞永远无用，而是说其补出的值依赖先验，必须用独立真值验证**已接受错误率**，不能把预测置信度直接当物理测量。RGB 边缘能提供附加信息但也不等于几何边缘：实体墨线是颜色变化，未必是曲面折线；皮肤纹理同样不必对应深度跳变。多视角重观测可增加可见集合，但 Eye-in-Hand 运动必须重新做时空标定、视野和软组织运动资格。

## 10. 第一部分：人工点选、实体画线、重观测接口 R15-7

**人工点选**：操作者在 RGB 图上指定有序点与方向；**实体画线**：先在非人体仿体上获取真实墨线 RGB 检测结果，再由操作者确认起终点、笔顺与分叉。两入口均输出 `OrderedStroke`，不把像素连通图 `SupportGraph` 当作指令。自动穴位/点位识别以后只替换候选点生成，不替代证据门。每个路点必须保存 `rgb_frame_id`、`depth_frame_id`、原始时戳/时钟域、`K_D/K_C` 版本、`T_CD` 方向、目标轴向深度、`visibility_state`、`source_pixel_ids`、拒绝原因及独立真值验证状态。

\[
\mathrm{Decision}(i)=
\begin{cases}
\mathrm{HOLD}, & \text{坐标/时间/标定谱系缺失};\\
\mathrm{REOBSERVE}, & \text{目标可见性未知、深度空洞或遮挡疑点};\\
\mathrm{REVIEW\_ONLY}, & \text{离线曲面候选与全部非人体证据齐全};
\end{cases}\quad \mathrm{robot\_command}=\varnothing.\tag{R15-7}
\]

当前所有案例只有 `REVIEW_ONLY` 级别的解析仿真结果，**没有**真实硬件路径放行。重新观测应以独立非人体靶标验证能减少目标可见性缺口为前提，不能简单重复同一视角采集后宣称消除系统误差。

## 11. 第二部分：刮板边缘、接触几何与姿态规划 R15-8

即使中心线的每个 RGB 深度点都正确，刮痧板具有有限工作边缘 `r_G(a)`，边缘两侧可能跨过缺测或遮挡边界。工具真实几何 `T_EG`、刮板边缘 CAD/扫描、装夹重复性、有效接触宽度必须实测；不能用“一个 TCP 点 + 一个法向”自动代表整条工作边缘。若 `T_BE(s)` 为 FR5 法兰沿路径的姿态，则：

\[
\mathbf x_B(s,a)=T_{BE}(s)T_{EG}\begin{bmatrix}\mathbf r_G(a)\\1\end{bmatrix},\quad
E_{\mathrm{edge}}(s)=\max_{a\in[a_0,a_1]}\mathrm{dist}(\mathbf x_B(s,a),\mathcal S_{\mathrm{validated}}).\tag{R15-8}
\]

`E_edge` 是待验证的几何覆盖量，不是压力，也不能凭当前合成图给出数值。**路径中心已接受≠工具边缘已接受**；工作边缘任何区域没有可靠曲面支持，应先拒绝姿态规划或重新观测。优化器只能在实测工具、独立仿体和固定姿态强基线失败后解冻；本轮不报告姿态优化成功率。

## 12. 第三部分：六维力觉、工作程/返程策略与安全 R15-9

FAIRINO 官方 Python SDK 4.0.0 有 `FT_GetForceTorqueOrigin`、`FT_GetForceTorqueRCS`、`FT_SetZero`、`FT_Guard`、`FT_Control`；实际 FR5 的固件/传感器配置、工具负载、坐标系、零点与数据新鲜度尚未取得。六维腕力读数只包含合力和合矩，不能唯一恢复刮板边缘的局部压力。定义离线状态机 `HOLD→APPROACH→WORK→UNLOAD→RETURN_OFF_SURFACE / RETURN_LIGHT→RETRACT`，其中返程轻力与离面返程必须在**非人体**台架分别评价，不以临床阈值放行。

\[
\mathbf w_O=\begin{bmatrix}\int_{\mathcal C}d\mathbf f\\\int_{\mathcal C}(\mathbf r-\mathbf o)\times d\mathbf f\end{bmatrix},\qquad
\mathrm{RETURN\_eligible}=e_{\mathrm{unloaded}}\land e_{\mathrm{force\_fresh}}\land e_{\mathrm{independent\_limit}}.\tag{R15-9}
\]

`FT_Control` 是强基线，不应将普通恒力 PID 重做为博士创新。视觉几何不合格、卸载未确认、力觉时间戳过期、重力补偿未知或独立保护缺失时只能 HOLD。R15 脚本与 `offline_gate.py` 无 FAIRINO SDK 导入、无 TCP/IP、无机器人运动指令；测试不是安全认证。

## 14. 误差预算、统计单位、效度威胁 R15-10

相机深度、像素、K、手眼、时钟、表面运动、刮板装夹和力觉零点误差不能互相替代。对目标轴向深度与几何点，局部一阶传播可写为：

\[
\delta\mathbf p_B\approx J_z\delta z+J_{uv}\delta\mathbf u+J_K\delta\boldsymbol\kappa+J_{CD}\delta\boldsymbol\xi_{CD}+J_{EC}\delta\boldsymbol\xi_{EC}+J_t\delta t+J_G\delta\mathbf g,\quad
\Sigma_{p_B}\approx J\Sigma J^T.\tag{R15-10}
\]

这里 `Σ` 包含相关项，系统性标定错配不能通过重复观测自动平均。**本轮没有真实 Σ**。另外，本轮报告的是 `|z_hat−z*|`，不是完整三维欧氏轨迹误差；低 z 误差仍可能有大切向误差。无畸变、无噪声、刚性两平面、规则矩形、固定相机、无软组织变形、单次前向取整都是明显简化；即使 63 组合都表现一致也不产生真实设备置信区间。合成参数来自公开仓库，但**不表示 TUM 图像曾被本轮运行**。

统计必须至少同时给出：覆盖率、已接受点超预算率（明确分母）、完整路径资格率、最大误差、边缘分层结果、拒绝/重拍代价；按**独立采集会话、工具重装、仿体曲面**分组估计不确定度，禁止把同一图的邻近像素当独立受试者。对皮肤人体接触的安全阈值只能来自专门风险评估与伦理程序，不能从 10mm 合成判据推导。
