# FR5刮痧研究资料 Agent 使用约定

1. 从 [V3.0起始页](guasha_v3_20261022/00_START_HERE.md) 和 [详细规则](guasha_v3_20261022/AGENTS.md) 开始。
2. M1屏幕点选、M2屏幕连续画线、M3候选点/模板规划必须全部走统一离线路径。
3. 开发禁止连接FR5、相机与任何硬件；不产生可直接下发到真实FR5的运动命令。
4. 读主规格、数学文档和需求JSON后进行全量实现及自动验收；旧历史报告只在对应问题出现时按需读取。
5. 旧研究证明了某些条件或反例，不证明本项目已经实机验证。缺失原始资料的AUTO/DEV轮次不能编造。
